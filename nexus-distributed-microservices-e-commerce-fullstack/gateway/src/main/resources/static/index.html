Nexus Distributed Commerce

Dark control plane for a Kafka-backed e-commerce saga.

Gateway routes requests to independent Order, Inventory, and Payment services. Kafka coordinates a choreography-based saga so each service owns its data and rollback events keep distributed state consistent.

Order Created

Order service records a pending order and publishes an event.

Stock Reserved

Inventory service reserves available stock or rejects the request.

Payment Authorized

Payment service records the transaction after inventory is reserved.

Order Confirmed

Order service confirms the saga after payment completion.

Rollback

Payment failure cancels the order and releases reserved stock.

Create Order

Submit through the Gateway. The API returns immediately while Kafka finishes the saga.

POST /api/orders

Inventory

Inspect stock and reserved quantities after saga events are processed.

GET /api/inventory

Payments
